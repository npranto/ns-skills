### spike

Answer a design or technical question. Throwaway: no spec, tickets, tests, or PR. Start with `/ns-route "<question>"`.

```
discover? ─▶ grill? ◆ (frame the question) ─▶ mp:research (factual unknown) | mp:prototype (design or interaction unknown)
   ─▶ findings ─▶ stop, or hand off to feature / architecture / proposal
```

- `mp:research` writes its findings to a Markdown file.
- Prototype code is never merged; `close` checks for leftovers later.
