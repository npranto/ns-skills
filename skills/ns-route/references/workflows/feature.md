### feature

Add a capability to an existing system. `/ns-flow-feature "<feature>"`

```
branch? ─▶ [PLAN] ─▶ [TICKET] ×N ─▶ [FEATURE-END]
                     └─ or hand independent low or medium risk tickets to agents (delegate)
```

- `branch` up front only if you want the spec and planning docs on their own branch.
- One ticket is fine for a small feature.
